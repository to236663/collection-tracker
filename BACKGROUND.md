# Project Title - Collector's Notebook 

## Project Description
This React project is a collection tracker app that allows for users to track their collections and the items in there collections. Users will be able to create collections in the app and be able to add items within the list as their collection grows. They will also be able to edit and/or delete their collections or items within the collection. On the home page, users will be able to pin collections to the very top of the list for easy access to important collections they are keeping track of. In each collections page, users will also be able filter items based on price and collected status. In this same page users will also be able to "check" items to signify that it has been collected, which will alter the status of the item from uncollected (unchecked) to collected (checked). 

## Features
1. Add/Edit/Delete Collections
2. Add/Edit/Delete Items within collections
3. Pin Collections on the main page 
4. Filter Items in collections by Status (Collected or Uncollected)
5. Check Off Items in collections
